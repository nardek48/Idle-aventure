🗺️ Atelier Écrans — Production

Objectif : séparer la routine de la gestion, et les bâtiments des chaînes de craft. L'écran Production devient un tableau de bord à 2 vues (double bouton) : Production = récolter/surveiller les 6 bâtiments, Ateliers = piloter les 12 ateliers d'un seul écran.

État simulé : milieu de Forêt · 3 stocks pleins · 2 ateliers à l'arrêt
Écran 1 — Tableau de bord (double bouton Production | Ateliers) Vue Ateliers v4 : la carte COMPLÈTE — style maquette + tout le fonctionnel réel. 4 choix de simplification jugeables : (1) ♻️ activé → la ligne de craft manuel disparaît (couper le toggle pour forcer un lot à la main) ; (2) quantité par lot auto = mini-stepper inline à côté du toggle ; (3) file = cases + entrée courante (temps + barre), ✕ sur les lots suivants ; (4) amélioration = bouton coût seul en haut à droite, l'effet est confirmé au toast. Moulin = auto ON · Boulangerie = manuel + alerte intrants · Cuisine = 3 recettes + alerte réserve.
Écran 2 — Détail bâtiment : Champs (zones seules) Allégé : les ateliers sont partis dans la vue Ateliers. Reste : en-tête minimal + récolte locale, zones 3×3 avec actions groupées.
