# Aethervale v3.445.0 — Les règles au départ

Idée de Seb : les règles du Grimoire sont figées pendant la sortie, la préparation est donc le dernier moment pour les revoir. Option 2 validée (`atelier/regles-preparation.html`).

## Ce qui change (préparation de sortie)
- Sous les presets, **les règles avec lesquelles tu pars**, en lecture : condition → action, marque « Contre », emplacements libres.
- Preset choisi : la liste montre **ses** règles, et l'aperçu des traits ennemis en tient compte.
- **« Modifier mes règles »** ouvre l'onglet Grimoire (un preset choisi devient d'abord tes règles actuelles).
- Un trait ennemi sans réponse a son raccourci **« Règle › »** vers le Grimoire.
- Dans le Grimoire, **« ↩ Revenir à la préparation »** rouvre la feuille avec tes choix (potions, objets).
