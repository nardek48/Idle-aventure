Ce que j'en vois

  • B est trop petit : les pictogrammes flottent dans la case, la barre se lit moins bien qu'aujourd'hui.
  • C tient la case et se lit bien de loin : silhouettes simples, une seule teinte dorée, plus de pastille ronde autour.
  • Ils sont faits pour le kit de la coque (même or poli). Seuls dans la barre actuelle, ils changent déjà le ton : plus sobre, plus « interface ».
  • Les mêmes fichiers servent aussi dans « Quoi de neuf » : ils y changeraient avec.
