Chaque fenêtre est le vrai DOM du jeu (v3.701, capturé dans Chromium à 320×568, héros Rôdeur, partie avancée ; fenêtres ouvertes par buildTutorialModalHTML et openVillageBuildingSheet) rendu avec le vrai CSS élagué, dans un cadre de 320×568 ou 390×844. Les variantes ajoutent leur CSS et, pour le clavier, le petit script qu'elles proposent au jeu. Les mesures sont prises dans le cadre : pixels cachés, bouton masqué ou non (point par point), et, pour le clavier, des pressions de Tab et d'Échap rejouées. Elles se refont sur ton iPhone à chaque changement ; le tableau donne le relevé Chromium de toutes les combinaisons. Cadre vert : conforme ; rouge : défaut.
